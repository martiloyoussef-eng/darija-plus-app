## 🎯 One-Click Deploy (Choose Your OS)

### **Windows (PowerShell)**
```powershell
cd C:\path\to\darija-plus-app
.\deploy.ps1
```

### **Mac/Linux (Terminal)**
```bash
cd path/to/darija-plus-app
chmod +x deploy.sh
./deploy.sh
```

✅ Installs Expo CLI + EAS CLI
