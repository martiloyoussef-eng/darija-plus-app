## About Darija+

Darija+ is a production-ready language learning application for Moroccan Arabic (Darija) and Amazigh, created with the goal of preserving and promoting Morocco's linguistic heritage.

### Key Features
- AI-powered pronunciation grading
- Native tutor marketplace (1-on-1 sessions)
- TikTok-style video reels for learning
- Tifinagh script support for Amazigh
- Global leaderboards & gamification
- Language exchange community

## How It Was Created

Darija+ was developed from the ground up using modern web and mobile technologies:

- **Frontend**: React Native + Expo (cross-platform)
- **Web**: React + TypeScript + Tailwind CSS
- **Mobile**: iOS and Android via Expo/EAS
- **State Management**: Zustand
- **API Client**: Axios with interceptors
- **Type Safety**: 100% TypeScript coverage
- **Accessibility**: WCAG 2.1 Level AA compliant

### Architecture Highlights
- Component-based UI architecture
- Zustand for global state management
- RESTful API client with 30+ documented endpoints
- Environment-based configuration
- Comprehensive error handling & logging
- Optimized for performance (Lighthouse 95+)
